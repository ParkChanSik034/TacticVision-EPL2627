# ADR-001: 모노레포로 시작한다

- Status: Accepted
- Date: 2026-08-04

## Context

현재 TacticVision은 웹 앱, TVS 문서, 구조화 데이터, 백엔드 API, 향후 Intelligence Engine이 서로 긴밀하게 연결되어 있다. 각 백엔드 또는 기능별로 저장소를 나누면 초기 단계에서 변경 동기화와 배포 관리 부담이 커진다.

## Decision

초기에는 하나의 모노레포에서 다음을 함께 관리한다.

- Web App
- Backend API
- TVS 문서
- Taxonomy 데이터
- Database Schema
- 테스트

백엔드는 모듈형 모놀리스로 시작한다.

## Consequences

### 장점

- 문서·데이터·코드 변경을 하나의 PR에서 검토 가능
- 초기에 배포와 버전 관리가 단순함
- 공통 타입과 검증 규칙을 쉽게 공유

### 단점

- 저장소 크기가 커질 수 있음
- 권한 분리가 필요한 시점에는 재구성이 필요함

## 분리 조건

다음 조건이 실제로 발생하면 별도 저장소를 검토한다.

- 독립 배포 주기가 필요함
- 별도 인프라 또는 연산 자원이 필요함
- 별도 팀이 독립적으로 운영함
- 외부 공개 SDK 또는 API 제품이 됨
