# TacticVision Bluebook v1.0

## 존재 이유

스포츠를 보는 것을 넘어, 이해하게 만든다.

## Mission

스포츠 데이터를 맥락·비교·상호작용으로 연결하여 사용자가 더 나은 스포츠 의사결정을 내리도록 돕는다.

## Vision

전 세계 스포츠 팬과 전문가가 가장 먼저 찾는 Sports Intelligence Platform.

## Slogan

**Stop Searching. Start Understanding.**

## 내부 장기 비전

**Build the Operating System for Sports Intelligence.**

## Core Principles

1. **Understand Before Judge** — 숫자를 판단하기 전에 맥락을 설명한다.
2. **Context Matters** — 데이터는 역할·전술·상황과 함께 제공한다.
3. **Compare Everything** — 선수·팀·감독·전술·경기를 비교할 수 있어야 한다.
4. **Interactive First** — 읽는 서비스가 아니라 탐색하고 조작하는 서비스를 만든다.
5. **Built for Professionals, Simple for Everyone** — 전문가 수준의 깊이를 유지하면서도 누구나 이해할 수 있어야 한다.

## Product Rules

- 모든 기능은 사용자의 스포츠 이해를 높여야 한다.
- 기능보다 Workflow를 우선한다.
- 모든 데이터는 연결되어야 한다.
- 모든 비교는 저장·공유·재사용할 수 있어야 한다.
- AI는 결론뿐 아니라 근거와 불확실성을 제시해야 한다.

## Business Model

```text
Free → Pro → Scout → Coach(향후) → Enterprise
```

## 확장 원칙

Football을 첫 모듈로 시작하지만, Basketball·Baseball·F1·Volleyball·eSports 등 다른 종목을 추가할 수 있는 공통 구조를 유지한다.
