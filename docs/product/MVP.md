# TacticVision Football MVP

## 핵심 사용자

- 축구 전술 팬
- FM·EA FC 사용자
- 축구 콘텐츠 제작자
- 초기 스포츠 분석 종사자

## 핵심 사용자 흐름

MVP는 Home을 공통 진입점으로 사용하고, 사용자의 목적에 따라 두 가지
주요 경로를 제공한다.

```text
Home
├─ 팀·선수·감독 탐색
│  └─ 상세 정보
│     └─ Team·Player·Manager Compare
│        └─ 비교 결과 확인
└─ 경기 탐색
   └─ Match Hub
      └─ Match Lineups
         └─ Tactical Board
            └─ 전술 배치 및 분석 결과 확인
```

### 경로 A — 대상 탐색과 비교

사용자는 Home에서 팀·선수·감독을 찾고 상세 정보를 확인한다. 필요하면
동일한 유형의 대상을 비교하고, 비교 결과를 확인하는 것으로 흐름을 마친다.

### 경로 B — 경기와 전술 분석

사용자는 Home에서 경기를 선택해 Match Hub로 이동한다. 라인업을 확인한 뒤
Tactical Board에서 포메이션과 선수 배치를 검토하는 것으로 흐름을 마친다.

두 경로는 서로 독립적으로 사용할 수 있다. 모든 사용자가 비교 화면이나
Tactical Board를 반드시 거칠 필요는 없다. AI Match Simulation은 이 MVP
사용자 흐름에 포함하지 않는다.

## MVP 포함 범위

### P0 — 핵심 기능

- 홈 대시보드
- EPL 팀 정보 및 상세 화면
- 선수 정보 및 상세 화면
- 감독 정보 및 상세 화면
- Team Compare
- Player Compare
- Manager Compare
- Match Hub 및 Match Lineups
- Tactical Board

### P1 — 품질 기준

- 기본 반응형 화면
- 데이터 로딩 실패 및 빈 상태 처리
- 데이터 간 연결 검증
- 기본 접근성
- 주요 브라우저 동작 검증

위 항목은 MVP에 포함하기로 확정한 범위다. 범위 포함은 구현 완료를
의미하지 않으며, 각 기능의 구현 상태와 완료 조건은 후속 Issue에서 관리한다.

## 기능 우선순위

우선순위는 개발 착수와 출시 판단에 사용하는 기준이다. 같은 우선순위 안의
구체적인 작업 순서는 로드맵에서 관리한다.

| 우선순위 | 의미 | 대상 | 완료 판단 |
| --- | --- | --- | --- |
| P0 | 핵심 사용자 흐름을 작동시키는 필수 범위 | 실행 구조, 데이터 구조, Home, 상세 화면, Compare, Match Hub, Tactical Board | 누락 시 MVP 핵심 흐름을 완료할 수 없으므로 출시 불가 |
| P1 | 공개 가능한 품질을 위한 출시 전 필수 범위 | 반응형, 로딩·오류·빈 상태, 데이터 연결, 접근성, 브라우저 검증 | P0 구현 후 검증하며, 미완료 시 공개 출시 보류 |
| P2 | MVP 검증 이후 검토할 확장 범위 | 계정, 저장·공유, AI 분석, 시뮬레이션, 고급 Scout, 유료 기능, PWA, 커뮤니티, Enterprise API | 현재 MVP 출시 조건에 포함하지 않음 |

### 우선순위 변경 원칙

- P0 기능을 제거하거나 P2 기능을 MVP에 추가할 때는 Issue에서 근거를 남긴다.
- P1은 후순위 기능이 아니라 P0 구현 이후 반드시 통과해야 하는 출시 조건이다.
- 일정이 부족해도 P0의 완료 조건을 축소하지 않는다. 범위를 조정할 때는 기능
  자체를 명시적으로 제외하고 관련 문서를 함께 수정한다.
- P2 기능은 P0·P1 완료와 MVP 사용자 검증 이후 별도 Issue에서 재평가한다.
