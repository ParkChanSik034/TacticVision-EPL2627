# TacticVision MVP Roadmap

## 운영 원칙

- 일정에 맞춰 작업량을 채우지 않고, 각 Sprint의 완료 조건을 충족하면 즉시
  다음 단계로 이동한다.
- 현재 구현된 화면을 다시 만드는 대신 데이터 확보·정규화·연동과 실제 사용자
  흐름 검증에 집중한다.
- P0는 핵심 흐름을 위한 필수 기능이고, P1은 공개 출시 전 반드시 통과해야 할
  품질 기준이다.
- 사용자 계정, 저장·공유, AI 분석, 경기 시뮬레이션 등 P2 기능은 MVP 완료를
  방해하지 않도록 별도 백로그에서 관리한다.

## Sprint 1 — 현재 구현 기준선 확정

### 작업

- `app/`을 MVP의 공식 실행 진입점으로 확정
- Home, 상세 화면, Compare, Match Hub, Match Lineups, Tactical Board 접근 확인
- 화면별 구현·부분 구현·미구현 상태 기록
- 깨진 링크, 버튼, 자산 경로와 콘솔 오류 수집
- 루트 `index.html`과 `apps/web/`은 레거시로 구분하고 삭제 여부는 별도 결정

### 완료 조건

- 두 핵심 사용자 흐름을 처음부터 끝까지 실행할 수 있다.
- 남은 작업이 화면별 체크리스트로 정리되어 있다.
- 공식 실행 경로와 레거시 경로가 명확히 구분되어 있다.

## Sprint 2 — 데이터 확보와 계약 확정

### 작업

- MVP에 필요한 팀·선수·감독·포메이션·전술·역할 필드 확정
- 데이터 출처, 수집 방식, 라이선스와 기준 시점 기록
- 외부 원본 데이터를 앱 내부 JSON 구조로 변환하는 규칙 정의
- ID, 팀 소속, 포지션, 감독, 포메이션 간 참조 무결성 검증
- 결측값, 중복값, 잘못된 참조와 업데이트 실패 처리 기준 정의

### 완료 조건

- 각 데이터 필드의 출처와 의미를 설명할 수 있다.
- 동일 대상을 연결하는 안정적인 ID 규칙이 있다.
- 검증 명령 또는 체크리스트로 데이터 오류를 반복 확인할 수 있다.
- 외부 데이터가 없어도 데모가 깨지지 않는 기준 데이터가 보존되어 있다.

## Sprint 3 — 실제 데이터 연동

### 작업

- 검증된 데이터를 Home과 검색 결과에 연결
- 팀·선수·감독 상세 화면에 동일한 데이터 계약 적용
- Team·Player·Manager Compare에 정규화된 비교 지표 연결
- Match Hub와 Match Lineups에 팀·선수 참조 연결
- Tactical Board에 포메이션·라인업·역할 데이터 연결
- 로딩, 오류, 빈 상태와 데이터 갱신 실패 처리

### 완료 조건

- 화면에 중복 하드코딩된 핵심 데이터가 없거나 예외가 문서화되어 있다.
- 탐색한 대상이 상세·비교·경기·전술 화면에서 동일한 정보로 표시된다.
- 잘못된 데이터가 들어와도 앱 전체가 중단되지 않는다.

## Sprint 4 — 핵심 사용자 흐름 검증

### 경로 A — 대상 탐색과 비교

`Home → 팀·선수·감독 탐색 → 상세 정보 → Compare → 비교 결과 확인`

### 경로 B — 경기와 전술 분석

`Home → 경기 탐색 → Match Hub → Match Lineups → Tactical Board → 분석 결과 확인`

### 완료 조건

- 각 경로를 새로고침 이후 처음부터 끝까지 수행할 수 있다.
- 뒤로 가기, 재선택, 검색 결과 없음과 잘못된 선택을 처리한다.
- 주요 버튼과 화면 이동에 막힌 지점이 없다.

## Sprint 5 — 공개 품질과 배포

### 작업

- 데스크톱과 모바일 기본 반응형 검증
- 키보드 접근, 포커스 표시, 레이블과 대비 점검
- 주요 브라우저에서 화면과 상호작용 검증
- 404 자산, 콘솔 오류와 데이터 요청 실패 제거
- 배포 환경에서 상대 경로와 JSON 로딩 확인
- README의 실행·검증·배포 방법을 실제 상태와 일치시킴

### 완료 조건

- P0 핵심 흐름과 P1 품질 기준을 모두 충족한다.
- 배포 주소에서 로컬과 동일한 핵심 흐름이 동작한다.
- 치명적인 콘솔 오류와 알려지지 않은 404가 없다.

## Sprint 6 — 지원용 포트폴리오 패키지

### 작업

- 문제 정의, 사용자, 데이터 모델과 분석 방법론 정리
- 대표 비교 사례와 전술 분석 시나리오 작성
- 주요 화면 스크린샷과 짧은 시연 순서 준비
- 기술적 선택, 데이터 한계와 향후 개선점 문서화
- 전력분석 업무에 적용 가능한 역량을 과장 없이 설명

### 완료 조건

- 저장소 README와 배포 주소만으로 프로젝트를 이해하고 실행할 수 있다.
- 3분 이내에 두 핵심 사용자 흐름 중 하나를 시연할 수 있다.
- 데이터 출처와 한계, 본인이 수행한 작업을 명확히 설명할 수 있다.

## MVP 이후 백로그

- TVS Position·Role·Playstyle·Archetype 표준 고도화
- Football DNA와 Tactical Function 관계 모델 확장
- Knowledge Graph 설계
- Scout Report 프로토타입
- 저장 및 리포트 기능
- AI 분석과 경기 시뮬레이션
- 사용자 계정, 유료 기능, PWA와 커뮤니티
