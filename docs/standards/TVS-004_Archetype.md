# TVS-004 Archetype Standard

## 정의

Archetype은 여러 Role과 Playstyle을 묶어 선수를 더 높은 수준에서 설명하는 **전술적 원형**이다.

## 초기 후보

- Creator
- Finisher
- Controller
- Destroyer
- Runner
- Leader

Archetype은 단일 포지션에 종속되지 않으며, 한 선수는 주 Archetype과 보조 Archetype을 가질 수 있다.
