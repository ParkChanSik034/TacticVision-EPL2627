# TacticVision Standards (TVS)

TacticVision Standards는 스포츠를 사람이 이해하기 쉽고, 소프트웨어와 AI가 일관되게 해석할 수 있도록 정의하는 내부 표준입니다.

## 표준 목록

| ID | 이름 | 상태 |
|---|---|---|
| TVS-001 | Position Standard | draft |
| TVS-002 | Role Standard | draft |
| TVS-003 | Playstyle Standard | draft |
| TVS-004 | Archetype Standard | draft |
| TVS-005 | Tactical Function Standard | draft |
| TVS-F001 | Football DNA Standard | planned |
| TVS-AI001 | Player Analysis Standard | planned |

## 공통 상태

- `draft`: 아이디어와 초기 설계
- `review`: 내부 검토 및 사례 검증
- `approved`: 실제 데이터와 기능이 따르는 승인 기준

## 버전 규칙

- `0.x.x`: 초안 및 검토 단계
- `1.0.0`: 최초 승인
- `1.x.x`: 하위 호환되는 추가·수정
- `2.0.0`: 정의나 데이터 구조의 중대한 변경
