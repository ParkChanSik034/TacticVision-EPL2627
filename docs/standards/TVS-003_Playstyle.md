# TVS-003 Playstyle Standard

## 정의

Playstyle은 선수가 Position과 Role을 수행하는 과정에서 반복적으로 나타내는 **행동 패턴과 성향**이다.

## 초기 분류

- Attack
- Creation
- Possession
- Defense
- Transition
- Physical

## 예시

- Direct Runner
- Clinical Finisher
- Tempo Controller
- Press Resistant Carrier
- Aggressive Presser
- Recovery Defender

## 필수 필드

- playstyle_id
- name
- category
- description
- observable_behaviors
- related_roles
- supporting_attributes
- supporting_statistics
- compatible_playstyles
- conflicting_playstyles
- status
- version
