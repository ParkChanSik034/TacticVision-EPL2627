# TVS-005 Tactical Function Standard

## 정의

Tactical Function은 선수가 팀 전술 안에서 만들어내는 **구조적 효과 또는 전술적 결과**를 뜻한다.

## 예시

- Attack Last Line
- Create Central Overload
- Stretch Defensive Width
- Link Build-up
- Protect Rest Defense
- Trigger High Press
- Progress Through Half-space

같은 Role이라도 경기 상황, 감독 철학, 주변 선수 배치에 따라 다른 Tactical Function을 수행할 수 있다.
